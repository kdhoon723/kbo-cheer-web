## 1. 테스트 방식

| 방식 | 도구 | 위치 | 실행 |
| --- | --- | --- | --- |
| 단위 | Vitest | `src/**/*.test.ts` | `npm test` |
| E2E | Playwright Test(Chromium) | `e2e/*.spec.ts` | `npm run test:e2e` |
| 수동 | 브라우저(Playwright MCP로 조작·측정) | 결과 문서에 절차와 값 기록 | 사람이 다시 따라 할 수 있게 절차를 적음 |

- "자동" 열: 단위 = 단위 테스트, E2E = E2E 테스트, 수동 = 수동 실행.
- `[API]`는 YouTube Data API를 실제로 부르는 테스트다(`.env.local`의 키 필요, 할당량 사용). 키가 없으면 E2E에서 건너뛴다.
- `[YT]`는 YouTube 영상을 실제로 재생하는 테스트다(인터넷 필요).
- 공통 사전 조건(따로 적지 않으면): 개발 서버 `http://localhost:5173`, LocalStorage를 비운 상태(처음 데이터 507곡이 들어감), 화면 1280×800.
