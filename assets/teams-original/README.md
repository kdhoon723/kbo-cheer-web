# 구단 엠블럼

각 구단 공식 BI 페이지에서 받은 엠블럼이다. 비상업 학습용 과제에서 구단을 알아보는 표시로만 쓰며, 상표와 저작권은 각 구단에 있다. 원본 색은 바꾸지 않았고 흰 배경만 투명으로 바꾸고 여백을 잘랐다.

이 폴더는 원본 보관용이라 배포물에 들어가지 않는다. 앱은 `node scripts/optimize-logos.mjs`로 만든 `public/teams/<팀 ID>.webp`(긴 변 132px 이하, 원본보다 키우지 않음)를 쓴다.
